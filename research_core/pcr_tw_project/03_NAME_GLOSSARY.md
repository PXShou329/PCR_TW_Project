# 03 譯名與術語對照（NAME GLOSSARY）

> 原則：一切名稱以**台服官方譯名**為準；日文名併記供搜尋用；中國服譯名不得作為主名稱。
> 標註格式：每列附來源可靠度（A–E）與查證日期；【待查證】表示尚未取得官方或可靠來源。

## 角色命名規則

1. 角色主名稱＝台服官方譯名（例：凱留、佩可莉姆、可可蘿、若菜）。
2. 同名角色的不同版本**必須**以版本後綴區分（例：若菜（冬日））。
3. `18_TW_CHARACTER_AVAILABILITY.csv` 的 `unit_key` 為穩定主鍵，格式：`<羅馬拼音>_<版本代碼>`，**一經建立不得更改**。
4. 台服未公布譯名的日服新角，暫用日文名並標【待查證】，不得自創中譯（見 12 同步規則）。

- 新增角色或術語：先查台服官方譯名（A 級），查不到暫用日文名＋【待查證】。
- 本表與台服官方公告不一致時：以官方為準修正，`99_CHANGELOG.md` 記一行。
