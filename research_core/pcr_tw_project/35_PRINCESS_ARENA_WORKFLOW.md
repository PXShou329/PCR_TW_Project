# 35 公主競技場研究流程（PRINCESS ARENA WORKFLOW）

> 用途：公主競技場（三隊制）問題的研究與回答流程。硬規則見 Instructions §6.4；
> 一般策略見 `36_PRINCESS_ARENA_STRATEGY_LIBRARY.md`；規劃格式見 `37_PRINCESS_ARENA_PLANNER_SCHEMA.md`；
> 研究記錄於 `38_PRINCESS_ARENA_RESEARCH_LOG.md`。

## 1. 資訊收集

- 已知敵方隊伍：逐隊辨識五人＋版本（同 30 §1）。
- **隱藏隊伍**：後兩隊被隱藏時，已知與推測必須分開；推測附信心（高／中／低）與依據（常見組合、該對手歷史配置），不得假裝知道完整防守。

## 2. 規劃原則（三戰兩勝）

1. 三隊各五人、**角色不得重複**；每隊功能完整（坦／輸出／輔助成立）。
2. 核心角色資源衝突：明確標示哪些核心只能進一隊、代價是什麼。
3. 田忌賽馬：可用弱隊消耗對方強隊，保留王牌隊拿兩勝；說明取捨。
4. 出隊順序：每個順序建議必附策略理由（試探／主攻／保底、對面出隊習慣、隱藏隊風險）（對應 T34）。
5. 防守配置與進攻配置分開處理，不得混用同一組結論。

## 3. 三隊組合（Guide-Only）

- 只依台服公共可用角色（18）與三隊不重複約束；對每支敵隊分別取得候選反制池後組合求解（對應 T33／T50）。
- 每隊必須有可追溯解陣來源；無來源組合標【推測】並降信心。
- 不宣稱任何「帳號可用」；個人化問題依 Instructions §1 回答。

## 4. 輸出格式

依 37 Planner Schema：敵方已知／推測分區 → 三隊組合（順序＋理由＋取捨說明）→ 風險與隨機性 → 來源與可靠度。

## 5. 建檔

每次研究記入 38；有通用價值的策略抽象化後補進 36（不綁定個人帳號）。
